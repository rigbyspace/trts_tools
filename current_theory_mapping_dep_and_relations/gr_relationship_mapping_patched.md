# GENERAL RELATIVITY RELATIONSHIP AND DEPENDENCY MAP

## Purpose and Method

This document constructs an explicit dependency/relationship graph of four-dimensional General Relativity within a declared scope. It is not a textbook treatment and does not treat the theory as a flat list of equations. The primary object is the graph: nodes represent mathematical objects, operators, equations, identities, constraints, transformations, equivalence classes, observables, or formulation-specific representations; edges represent the mathematically specified relationships among them.

The graph is constructed recursively. A declared node set is used to identify established relationships. Any relationship that introduces a new object, operation, constraint, transformation, or equivalence class is evaluated as a candidate node and incorporated only when its status and preconditions are explicit. Recursion terminates only when the graph reaches **scope-qualified structural closure**: no additional nodes or edges are generated by the declared operations and inclusion rules without extending the declared scope. Closure therefore means closure of the map under specified rules, not exhaustion of all mathematics or all solutions of General Relativity.

Each established edge is intended to answer the following questions:

1. **What is the source and target?**
2. **What mathematical operation or logical relation connects them?**
3. **What preconditions are required?**
4. **What information is preserved, discarded, or recoverable only with additional data?**
5. **In what direction does the dependency run, and is the mapping reversible?**
6. **Which coordinate, gauge, formulation, or model choices affect the relationship?**
7. **What is the epistemic status of the relationship?**
8. **What fails or changes if a required premise is removed?**

## Declared Scope

The map covers four-dimensional covariant General Relativity together with the 3+1 (ADM) decomposition, exact diffeomorphism structure, selected matter models (perfect fluid, minimally coupled scalar field, electromagnetic field, and cosmological constant), energy-condition constraints, and linearised perturbation theory. Background-specific perturbation formalisms, alternative spacetime dimensions, non-metric gravity, specific exact-solution families, and numerical solution techniques are outside the universal closure claim unless explicitly introduced.

## Graph Ontology

Nodes are classified by role rather than by mathematical symbol alone. The classification is orthogonal to the node IDs used in the module inventories.

| Node Class | Meaning | Examples |
| :--- | :--- | :--- |
| **OBJECT** | Mathematical or physical entity represented in the theory | manifold, metric, curvature tensor, stress-energy tensor |
| **OPERATOR** | Operation acting on an object or class of objects | \(\partial\), \(\nabla\), Lie derivative, contraction |
| **EQUATION** | Relation imposed or defined between quantities | EFE, geodesic equation, linearised EFE |
| **IDENTITY** | Relation that follows from definitions or structural properties rather than dynamics | inverse identity, Bianchi identity |
| **CONSTRAINT** | Condition restricting admissible configurations or data | Hamiltonian constraint, energy condition |
| **TRANSFORMATION** | Map between representations or configurations | coordinate transformation, active diffeomorphism |
| **REPRESENTATION** | Formulation-specific repackaging of previously defined structure | ADM variables, tetrad variables |
| **EQUIVALENCE CLASS** | Collection of descriptions related by an equivalence relation | \([g]\), perturbative gauge class |
| **OBSERVABLE** | Quantity designated as physically interpretable within the declared model | scalar invariant, invariant mass, measurable response |
| **THEOREM** | Logical result requiring stated hypotheses | ADM equivalence, constraint propagation |

A node may participate in more than one role when the document explicitly distinguishes those roles.

## Edge Ontology and Dependency Grammar

An edge is represented conceptually as

\[
\boxed{\text{SOURCE}\xrightarrow[\text{preconditions}]{\text{relationship}}\text{TARGET}}
\]

The table field **Relationship Type** identifies the edge class. The principal classes are:

| Edge Class | Meaning | Information Effect |
| :--- | :--- | :--- |
| **Definitional** | Target is defined directly from source data | Usually information-preserving only in the stated representation; may be many-to-one |
| **Derived** | Target follows from prior definitions, identities, or equations | Depends on the derivation |
| **Constraint** | Source condition restricts the target or admissible state | Information is restricted rather than transformed |
| **Transformation** | Source is mapped to another description or configuration | Reversible when the stated inverse exists |
| **Equivalence** | Two descriptions encode the same structure under stated hypotheses | Information-preserving at the equivalence-class level |
| **Recoverability** | Target can be reconstructed from source plus stated auxiliary data | Conditional on complete auxiliary data |
| **Projection** | Target is obtained by contraction or projection of source | Generally information-losing |
| **Correspondence** | Two formulations or descriptions encode the same content | Conditional on the stated equivalence theorem |
| **Feedback** | Target or constraint depends back on an upstream node | Creates a directed cycle in the dependency graph |

## Information Preservation and Reversibility

**Reversibility** is not sufficient by itself to describe an edge. Each reduction or projection is also classified by information effect:

- **Information-preserving**: an inverse exists under the stated hypotheses.
- **Information-losing**: multiple source configurations map to the same target.
- **Conditionally recoverable**: information is recoverable only when additional nodes or structure are retained.
- **Constraint-restricting**: the edge narrows the admissible configuration space rather than representing a transformation.

When an edge is marked reversible, the inverse relationship must be stated or uniquely implied by the same declared data. A relationship is not considered reversible merely because the target equation can be algebraically rearranged if additional information has been discarded.

## Epistemic Status and Propagation

Every edge is assigned an epistemic status such as **Defined**, **Derived**, **Supported**, **Conditional**, **Approximate**, **Formal**, or **Unresolved**. The status applies to the path represented by the edge, not merely to the symbols appearing in its equation. A downstream path inherits the strongest limitation of any required upstream edge or node. Thus a formally valid calculation that depends on an unresolved construction remains formally or conditionally established rather than becoming exact merely because its algebra is exact.

## Counterfactual Dependency Test

For each structurally important dependency, the graph should answer:

> **What changes or ceases to exist if a required premise is removed?**

This test distinguishes mathematical necessity from a formulation choice. Examples include removal of metric compatibility or torsion-freedom from the Levi-Civita construction, removal of a foliation from ADM variables, removal of the Einstein equation from stress-energy conservation, or removal of a fixed background from linearised gauge constructions.

## Canonical Dependency Paths

The detailed edge tables provide the authoritative graph records. Each module should also expose its shortest or most structurally important dependency chains so that the graph can be read at both overview and edge-resolution scales. These paths are summaries of established edges, not substitutes for them.

### Material Findings – Module 1

1. **Direct dependencies**:  
   - \(g_{\mu\nu}\) is the foundational primitive; from it, one obtains \(g^{\mu\nu}\) (via matrix inversion, precondition \(\det g \neq 0\)), \(\det g\), and all index operations.  
   - No edge exists from \(g^{\mu\nu}\) back to \(g_{\mu\nu}\) except via the same inversion – thus the inverse relationship is bidirectional **provided** the precondition holds.

2. **Coordinate transformations**:  
   - All metric quantities transform according to tensor/density laws. These are exact, local, and reversible.  
   - The transformation relationships are **not** gauge transformations in the sense of diffeomorphism invariance; they are passive coordinate changes. Active diffeomorphisms are not treated in Module 1 (deferred to Module 4).

3. **Tetrad**:  
   - Introduced only as a formulation‑specific node. The relationship \(g = e e^T \eta\) is **not** a universal property of GR; it requires the explicit selection of the tetrad formalism. Its determinant relation remains unresolved unless the tetrad formulation is declared.

4. **Mathematical validity**:  
   - All operations (inversion, contraction, differentiation of determinant) are well‑defined for non‑degenerate metrics.  
   - Dimensional checks: \(g_{\mu\nu}\) is dimensionless in geometric units (or carries length² depending on convention); inverse carries inverse dimension; contraction \(g_{\mu\nu}g^{\mu\nu}=4\) is dimensionless and valid.

5. **Gauge status**:  
   - Coordinate dependence is explicit: all relationships involving \(g\) are covariant but not invariant. The Kronecker delta is the only invariant tensor in this module.

6. **Recursive closure within Module 1**:  
   - Starting from \(N1\)–\(N6\) (plus optional \(N11\)), all newly encountered nodes (e.g., transformed metrics, trace 4, determinant derivatives) have been connected. No additional primitive nodes emerge from the declared operations.  
   - The module is **closed** for the specified set: coordinate, metric, inverse, determinant, transformation, and index operations.  
   - New nodes like the connection or curvature are **not** part of Module 1 (they belong to Module 2). Their introduction would add edges, but that lies outside the current declared scope.

### Material Findings – Module 2

1. **Dependency chain**: The primary curvature-construction backbone is acyclic from metric to connection to Riemann, then to Ricci, scalar, Einstein, and Weyl; recoverability and identity edges are represented separately. No reverse dependencies exist without additional assumptions (e.g., solving differential equations). Recoverability of \(R_{\mu\nu}\) from \(G_{\mu\nu}\) is algebraic and reversible (added edge).

2. **Preconditions**:  
   - Torsion‑free (\(\Gamma^\rho_{\mu\nu}=\Gamma^\rho_{\nu\mu}\)) and metric compatibility (\(\nabla_\mu g_{\nu\rho}=0\)) are **explicit assumptions** of the Levi‑Civita connection in GR. They are not derived from the metric alone; they are imposed as physical requirements.  
   - The Bianchi identities rely on these preconditions; if torsion were present, the identities would gain torsion terms.

3. **Gauge status**:  
   - The Christoffel symbol is not a tensor: under coordinate transformations, it transforms inhomogeneously (with second derivatives of the coordinate change).  
   - All curvature tensors (Riemann, Ricci, Einstein, Weyl) are tensors and transform covariantly under coordinate changes. The Ricci scalar and Kretschmann scalar are coordinate invariants.  
   - The geodesic equation is coordinate‑dependent in form but its solution set is geometrically invariant (autoparallel curves).

4. **Invariants**:  
   - \(R\) and \(K\) are scalar invariants built from curvature. They are useful for distinguishing spacetimes (e.g., Schwarzschild has \(R=0\), \(K\neq0\)). However, \(K=0\) does **not** imply flatness in Lorentzian signature (unresolved candidate noted).

5. **Bianchi identities**:  
   - The **algebraic Bianchi identity** is a cyclic identity of the Riemann tensor arising from the torsion-free curvature structure.  
   - The **differential Bianchi identity** is the covariant differential identity for Riemann curvature. Its contraction gives \(\nabla_\mu G^{\mu\nu}=0\).  
   - The contracted identity is geometric, not an equation of motion. It becomes the stress-energy conservation law \(\nabla_\mu T^{\mu\nu}=0\) only after the Einstein field equation is imposed. This distinction is a required dependency in the graph.

6. **Recursive closure within Module 2**:  
   - Starting from N12–N14 and the metric from Module 1, the recursive discovery yields N15–N23 and the Bianchi identities.  
   - No additional fundamental curvature objects emerge from these definitions (e.g., the Cotton tensor is relevant only in 3D; we are in 4D).  
   - The Weyl tensor and Kretschmann scalar are terminal nodes; they do not lead to further universal geometric primitives.  
   - The module is **closed** with respect to the declared scope of 4D differential geometry and curvature.

### Material Findings – Module 3

1. **EFE as a constraint on geometry and matter**:  
   - The Einstein field equation is a tensor equation relating the Einstein tensor \(G_{\mu\nu}\) (built from the metric and its derivatives up to second order) to the stress‑energy tensor \(T_{\mu\nu}\). It is **not** an identity; it imposes 10 independent differential equations on the metric.  
   - The contracted Bianchi identity \(\nabla_\mu G^{\mu\nu}=0\) implies that **any solution** of the EFE automatically satisfies \(\nabla_\mu T^{\mu\nu}=0\). Thus, conservation of stress‑energy is a **derived consequence**, not an independent axiom (provided EFE holds). This is an exact, universal relationship.

2. **ADM decomposition is gauge‑dependent and formulation‑specific**:  
   - The ADM variables (\(\gamma_{ij}, K_{ij}, N, N^i\)) depend entirely on the choice of foliation (time function \(t\)). They are **not** additional fundamental degrees of freedom; they are a repackaging of the 4D metric.  
   - The relationships \(g_{\mu\nu} \leftrightarrow (N,N^i,\gamma_{ij})\) and the definitions of \(K_{ij}\) are **exact and reversible** within a given foliation.  
   - The Hamiltonian and momentum constraints (N41, N42) are **not independent field equations**; they are projections of the 4D EFE onto the normal and tangential directions of the foliation. They are **constraints** on the initial data, not evolution equations.

3. **Evolution equations**:  
   - The equation for \(\partial_t \gamma_{ij}\) (N43) is **merely the definition** of the extrinsic curvature; it is kinematic.  
   - The equation for \(\partial_t K_{ij}\) (N44) is the **dynamical content** of the EFE; it is a second‑order hyperbolic PDE system.  
   - Together with the constraints, the ADM system is **exactly equivalent** to the 4D EFE (this is a theorem, not an approximation).

4. **Constraint propagation**:  
   - If the constraints (N41, N42) are satisfied on an initial hypersurface, and the evolution equations (N43, N44) hold, then the constraints remain satisfied on all later slices. This is a **consequence of the Bianchi identities** and is exact. It demonstrates that the ADM formulation is consistent.

5. **Matter projection**:  
   - The decomposition of \(T_{\mu\nu}\) into \(\rho, S_i, S_{ij}\) is model‑independent in form, but the specific functional dependence of these projections on the matter fields is **model‑specific** (deferred to Module 5).  
   - Recovering \(T_{\mu\nu}\) from its projections is possible and reversible, provided all components (\(\rho, S_i, S_{ij}\)) are known.

6. **Dependency chain (4D → ADM)**:  
   ```
   g_{\muν} + foliation → (N, N^i, γ_{ij}) → K_{ij} → 3D curvature → constraints & evolution
   ```
   This chain is acyclic if foliation is fixed; the ADM variables are derived, not fundamental.

7. **Gauge degrees of freedom**:  
   - In ADM, the lapse \(N\) and shift \(N^i\) are **gauge degrees of freedom** corresponding to the freedom to choose the foliation. They do not appear in the physical content of the theory (they are not dynamical; they are multipliers in the action).

### Material Findings – Module 4

1. **Passive vs Active Diffeomorphisms**:  
   - **Passive** (coordinate change) is a relabelling of points; tensor components transform by the standard tensor law. Scalar fields satisfy \(R'(x') = R(x)\) – this is coordinate invariance.  
   - **Active** (gauge transformation in the field‑theoretic sense) is a map \(\phi:\mathcal{M}\to\mathcal{M}\) that pulls back the entire tensor field to a new field \(\phi^*g\) at the same coordinate \(x\). Under an infinitesimal active diffeo generated by \(\xi^\mu\), *any* tensor \(T\) changes as \(\delta T = \mathcal{L}_\xi T\). This is the relevant transformation for the "gauge problem" in perturbation theory.

2. **Gauge Dependence of Perturbations**:  
   - The metric perturbation \(h_{\mu\nu}\) is purely gauge‑dependent. Its transformation law, \(\delta_\xi h_{\mu\nu} = \nabla_\mu \xi_\nu + \nabla_\nu \xi_\mu\), is exact at first order.  
   - All perturbed curvature tensors (e.g., \(\delta R_{\mu\nu\rho\sigma}\), \(\delta R_{\mu\nu}\), \(\delta R\)) inherit this gauge dependence. In particular, \(\delta_\xi (\delta R) = \mathcal{L}_\xi \bar{R}\). Thus, \(\delta R\) is gauge‑invariant **only if** the background Ricci scalar is constant (or more generally, if \(\mathcal{L}_\xi \bar{R}=0\) for all \(\xi\), which means \(\bar{R}\) is constant). In a cosmological FLRW background, \(\bar{R}\) depends on time, so \(\delta R\) is not gauge‑invariant.  
   - The linearised Einstein tensor \(\delta G_{\mu\nu}\) transforms as \(\delta_\xi(\delta G_{\mu\nu}) = \mathcal{L}_\xi \bar{G}_{\mu\nu} = \kappa\,\mathcal{L}_\xi \bar{T}_{\mu\nu}\). Therefore, it is gauge‑invariant only in vacuum (\(\bar{T}_{\mu\nu}=0\)) or if \(\bar{T}_{\mu\nu}\) admits the same symmetries (e.g., cosmological constant with Killing vectors).

3. **Equivalence Classes**:  
   - The **exact** diffeomorphism equivalence class \([g]\) is the physical spacetime. This is a foundational principle of GR.  
   - In perturbation theory, the **gauge‑invariant class** \([h]\) is defined as the quotient of the space of perturbations by the action of the gauge group. However, constructing explicit representatives of this class (e.g., Bardeen variables) requires a background with symmetries to split perturbations into scalar/vector/tensor modes.

4. **Lie Derivative as the Engine**:  
   - The Lie derivative \(\mathcal{L}_\xi\) is the central operator linking infinitesimal diffeomorphisms, gauge transformations, and symmetries.  
   - For Killing vectors, \(\mathcal{L}_\xi g = 0\) defines an isometry; these vectors are symmetries, not gauge redundancies, because they leave the metric invariant (whereas a generic gauge transformation changes the metric).

5. **Recursive Closure within Module 4**:  
   - Starting from the concepts of active/passive diffeos, Lie derivatives, and their actions on all previously defined tensors (metric, connection, curvature), no additional fundamental structural nodes are discovered.  
   - The *specific construction of gauge‑invariant variables* (like Bardeen potentials, Regge‑Wheeler variables) is a special case requiring a matter background (e.g., FLRW) and a mode decomposition (scalar/vector/tensor). Since those backgrounds are not declared in the universal scope, the generic unresolved status is correctly marked.  
   - The distinction between exact diffeomorphism equivalence and perturbative gauge equivalence has been rigorously established and separated.

### Material Findings – Module 5

1. **GR Does Not Dictate the Form of Matter**:  
   - The Einstein equations \(G_{\mu\nu}=\kappa T_{\mu\nu}\) provide the coupling geometry–matter, but the specific functional form of \(T_{\mu\nu}\) (its "constitutive relation") is **external to GR**.  
   - The stress‑energy tensor need only satisfy:  
     (a) **Symmetry**: \(T_{\mu\nu}=T_{\nu\mu}\).  
     (b) **Conservation**: \(\nabla_\mu T^{\mu\nu}=0\) (derived from EFE + Bianchi).  
   - Any additional structure (perfect fluid, scalar field, anisotropic stress, viscosity, etc.) is a **model‑specific assumption** and must be declared explicitly. This is a core principle of the protocol.

2. **Conservation Equations Are Derivations, Not Independent Laws**:  
   - For each matter model defined, the equation of motion (e.g., Euler equation, Klein‑Gordon, Maxwell) is **derived** from \(\nabla_\mu T^{\mu\nu}=0\) by inserting the specific definition of \(T_{\mu\nu}\).  
   - This establishes a dependency chain:  
     `EFE → Bianchi identity → ∇T=0 → (matter definition) → matter field equations`.  
   - This preserves the fact that matter dynamics are not independent axioms in GR (provided the EFE holds).

3. **Energy Conditions Are Optional Constraints**:  
   - The Weak, Null, Dominant, and Strong energy conditions are **not** universal requirements of the Einstein equations. They are **admissible hypotheses** that can be imposed to restrict the space of allowed matter models (e.g., to prove singularity theorems or avoid pathologies).  
   - A perturbation that violates an energy condition must be classified as **"violates the imposed energy condition"** rather than **"mathematically forbidden by GR"** (within the declared energy-condition rules).

4. **Closure and Degrees of Freedom**:  
   - For a perfect fluid, the independent variables are \(\rho, p, u^\mu\) (with \(g_{\mu\nu}\) already present). The conservation equations provide 4 equations, but the system is not closed until an EOS \(p=p(\rho)\) (or \(p = p(\rho, s)\) with entropy advection) is supplied.  
   - This closure problem is a structural feature of the fluid model, not a deficiency of GR.

5. **Recursive Closure within Module 5**:  
   - Starting from the universal nodes (N24, N27) and introducing the model‑specific primitives (fluid variables, scalar field, EM field), the recursive discovery yields their respective stress‑energy tensors, conservation equations, and energy condition inequalities.  
   - No additional fundamental nodes emerge from these definitions (e.g., no new geometric objects beyond those in Modules 1–3).  
   - The module is closed for the **declared set of canonical matter models**. Any other matter model (e.g., anisotropic fluid, elastic medium, higher‑spin fields) would require additional nodes and edges but would follow the same structural pattern.  
   - The unresolved candidates are correctly identified as conditional, model‑specific, or optional.

### Structural Validation Rules for the Perturbation Layer

The perturbation map is evaluated as a graph transformation rather than as an isolated differential calculation. A perturbation is admissible only when the perturbed nodes remain within the declared node class, satisfy the required dimensional and tensorial types, respect the background equations and constraints to the stated order, and have their gauge content explicitly separated.

For each perturbative path, the validation sequence is:

\[
\boxed{\text{type check}\rightarrow\text{background dependency check}\rightarrow\text{constraint check}\rightarrow\text{gauge check}\rightarrow\text{propagation}\rightarrow\text{observable response}}
\]

A perturbation that fails an earlier condition is not propagated as though it were an admissible physical perturbation. Its terminal status is instead recorded at the failed edge as **inadmissible**, **constraint-violating**, **pure gauge**, or another explicitly supported category.

- **Status**: Admissible as a mathematical remapping, but **not a probe** of the linearised relationship network. Marked as **inadmissible for perturbative analysis** (unless non‑linear analysis is requested, which is unresolved).
